# kind|file|title
#   t  — преподаватель, файл лежит в t/
#   s  — группа, файл лежит в s/
#   zs — заочная группа, файл лежит в z/. Встаёт в общий список групп.
#   zt — заочное расписание преподавателя, файл лежит в z/. Отдельной
#        строкой в списке не появляется: эти пары подмешиваются в его
#        расписание из t/ — строки связываются по названию, третьему
#        столбцу («Иванов В.В.»), а не по имени файла.
#
# Примеры заочного отделения:
#   zs|OZY-2501|ОЗЮ-2501
#   zt|ivanov_vv|Иванов В.В.
